HOW IT WORKS
═══════════════════════════════════════════════════════════════

Step 1: Set Your Version
  Edit: version.py

  VERSION = "1.0.0"  ← Change this
  BUILD_DATE = "2026-02-13"

Step 2: Build Everything
  Run: build.bat

  What happens:
  1. Reads version from version.py
  2. Builds EXE with PyInstaller
  3. Creates dist_v1.0.0/ folder
  4. Copies EXE + service files
  5. Creates VERSION.txt and README.txt

Step 3: Result
  dist/
  ├── erp-cnc-adapter.exe          ← Raw build
  └── dist_v1.0.0/                 ← Distribution package ⭐
      ├── erp-cnc-adapter.exe
      ├── windows_service/
      │   ├── service_exe.py
      │   ├── install_service.bat
      │   ├── uninstall_service.bat
      │   ├── update_adapter.py
      │   ├── service_status.bat
      │   ├── restart_service.bat
      │   └── README.md
      ├── logs/
      ├── VERSION.txt
      └── README.txt

DISTRIBUTION WORKFLOW
═══════════════════════════════════════════════════════════════

For Version 1.0.0:
  1. Edit version.py → VERSION = "1.0.0"
  2. Run build.bat
  3. Copy dist_v1.0.0/ to target machine
  4. Run: windows_service\install_service.bat (as admin)

For Version 1.1.0:
  1. Edit version.py → VERSION = "1.1.0"
  2. Run build.bat
  3. Copy dist_v1.1.0/ to target machine
  4. Or use update script on existing installations

TESTING THE BUILD

1. Test the build:

2. Verify output:
   > cd dist\dist_v1.0.0

   You should see:

   - windows_service\ folder
   - logs\ folder
   - VERSION.txt
   - README.txt

3. Test local installation:
   > cd dist\dist_v1.0.0
   > Right-click windows_service\install_service.bat
   > Run as administrator

4. Verify service:
   > http://localhost:8000
